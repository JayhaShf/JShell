## 1. 发布结论

本版本完成 JShell 品牌与三平台资源切换、远程文件管理、SFTP 断线恢复、远程文本编辑、终端与编辑器混合分屏、独立编辑器窗口、动态任务栏标题及标签状态语义。

发布前质量门禁包括格式、单元测试、全目标检查、严格 Clippy、Release 构建、依赖审计和差异空白检查。除 `cargo audit` 中无可用修复版本的已知上游风险外，其余门禁必须零失败后才允许创建版本标签。

## 2. 主要变更

### 2.1 产品身份与发布资源

- 软件名称、二进制、Windows 资源、Linux 桌面入口和 macOS 应用包统一为 JShell。
- 保留透明 PNG 母版，并提供 Windows ICO、Linux PNG 和 macOS ICNS。
- 发布流程只向当前 `JayhaShf/JShell` 仓库写入 Release，不再更新上游 Homebrew Tap。
- 发布标签必须与 `Cargo.toml` 的包版本完全一致。

### 2.2 SSH 与代理

- SSH 会话支持直连、全局代理和自定义代理。
- SOCKS5、SOCKS5H、HTTP 与 HTTPS 统一到同一代理入口。
- 直连模式显式绕过环境和全局代理；状态区显示实际连接路线。
- HTTPS 代理执行证书链和主机名校验，连接失败不会静默降级为直连。
- 代理状态和错误日志不输出密码、认证头或完整 CONNECT 请求。

### 2.3 SFTP 文件管理与恢复

- Linux 文件列表展示文件类型、符号权限和八进制权限。
- 支持删除文件和目录；删除、上传、下载等有副作用操作在断线后不会自动重放。
- 单击文件行只聚焦，不切换复选框；双击目录进入，双击普通文本打开编辑器。
- SFTP 使用稳定句柄和连接监视器，检测断线后按退避策略恢复，并过滤旧连接的迟到事件。

### 2.4 远程编辑器与工作区

- SSH 终端与远程文本可在同一工作区左右或上下分屏。
- 文档可移动到独立窗口；主窗口保留分屏位置，关闭独立窗口只重挂，不自动保存。
- 自动换行作为全局偏好持久化，并应用到已打开和新打开的文档。
- 文档标签、工具栏、状态栏和窗口标题共用同一 dirty、保存和连接状态。
- 断线不会触发自动保存或覆盖远端文件；写入结果无法确认时保持 dirty，并显示“保存结果未知”。
- 普通文本使用 Tree-sitter 增量语法着色；Shiki 不接入原生终端热路径。

### 2.5 标签与系统集成

- 所有工作区标签使用类型色带：终端与远程文件采用不同基础色，警告、错误和不可用状态覆盖基础色。
- 命令输入显示开关移动到 SFTP 底部状态区，分页操作保持可见。
- Windows 主窗口和独立编辑器窗口动态显示当前任务，例如 `JShell - nginx.conf*`；混合工作区只显示当前文件名。

## 3. 保存与断线语义

1. 编辑内容先保存在本地内存中的文档模型，不会因为连接断开自动写回远端。
2. 只有用户执行保存，且连接在线、版本检查通过时，才发起远端原子写入。
3. 保存检查或写入期间禁止关闭对应独立窗口，避免窗口销毁导致任务完成路径丢失。
4. 写入阶段断线且无法确认结果时，不自动重试，不把文档标为已保存。
5. 关闭应用或 dirty 文档继续走统一的未保存确认流程。

## 5. 依赖审计残留

2026-07-30 实际执行 `cargo audit`：扫描 `1032` 个锁定依赖，发现 `1` 条漏洞和 `7` 条维护性告警，退出码为 `1`。本项目不增加忽略规则，也不把该结果描述为通过。

### 5.1 已知漏洞

- `RUSTSEC-2023-0071`：`rsa 0.10.0-rc.16`，Marvin Attack 计时侧信道，严重级别 `5.9 (medium)`。
- 引入链：`jshell -> russh 0.60.3 -> rsa 0.10.0-rc.16`，同时经过 `internal-russh-forked-ssh-key` 使用。
- RustSec 当前明确显示 `No fixed upgrade is available!`，因此本版本只能记录并持续跟踪上游 `russh`/`rsa` 修复。

### 5.2 维护性告警

| 公告 | 依赖 | 主要引入方 |

## 6. 手动验证边界

自动化可覆盖状态机、布局、权限格式、保存决策、事件代次、配置兼容和构建结果，但以下路径仍需要可用 SSH/SFTP 服务器进行发布后验收：

- 静默断线后的 SFTP 自动恢复和当前目录刷新。
- 真实 Linux 服务器的权限显示、目录双击、删除失败与重试。
- 终端与远程文档混合分屏、独立窗口重挂和远端冲突保存。
- Windows 任务栏在多个主/独立窗口之间的实时标题切换。

这些限制不会被写成“已自动验证”；发布说明应保留为已知验收项。
