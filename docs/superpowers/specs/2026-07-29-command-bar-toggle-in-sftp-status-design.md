# 命令输入切换按钮下移设计

日期：2026-07-29

## 目标

把窗口顶部工具区中的“显示命令输入”按钮移动到 SFTP 状态栏，也就是远程路径、传输记录和面板展开/折叠操作所在的一行。命令输入框本身继续显示在终端底部，不改变命令编辑、历史记录或发送逻辑。

## 方案选择

状态栏从左到右排列为：

1. 当前 SFTP 状态或远程路径，占用剩余空间并允许截断。
2. 命令输入切换按钮。
3. 传输记录按钮或传输进度。
4. SFTP 面板展开/折叠按钮。

命令按钮放在“传输记录”之前，使“展开/折叠”继续作为最右侧的面板级操作。未采用放在远程路径左侧的方案，因为它会混入状态信息；未采用放在“展开面板”之后的方案，因为这会破坏最右侧按钮与面板折叠行为的对应关系。

## 显示与交互

- 仅当当前活动终端是已连接的 SSH 会话时显示命令按钮。
- SFTP 已就绪、尚未就绪、无活动 SFTP 实例、面板展开和面板折叠时，按钮都位于同一状态栏位置。
- 点击按钮继续调用现有命令输入开关，不创建第二套输入框或状态。
- 打开命令输入后，输入框继续渲染在终端内容下方；再次点击关闭。
- 顶部工具区移除原命令按钮，避免同一操作出现两个入口。
- 终端搜索、分屏和新建会话按钮保持原位置和行为。

## 外观与可访问性

- 复用现有终端图标和小型幽灵按钮样式，与传输记录及面板按钮保持同一视觉层级。
- 状态栏中的按钮使用固定内容尺寸；左侧路径或状态使用 `flex` 和截断承担窄窗口收缩。
- 命令按钮保持图标入口，并提供工具提示。
- 命令输入关闭时提示“显示命令输入”，打开时提示“隐藏命令输入”；英文同步提供对应翻译。
- 不在状态栏额外显示长文字标签，避免传输进度出现时挤压面板操作。

## 实现边界

- 修改 `src/app/ui.rs`，从顶部工具区删除入口，并在 SFTP 状态栏的两个渲染分支中加入入口。
- 修改 `src/app/command_history.rs`，让按钮提示随 `command_bar_open` 状态变化，并采用状态栏样式。
- 复用 `locales/zh-CN.yml` 和 `locales/en.yml` 中已有的 `command_bar_toggle` 与 `command_bar_hide` 翻译，不新增重复键。
- 如直接在两个 SFTP 分支插入按钮会产生重复判断，则提取只负责显示条件和按钮渲染的小型辅助方法；不借此重构整个 SFTP 面板。

## 非目标

- 不移动命令输入框本身。
- 不改变命令执行、历史记录、补全、快捷键或 SSH 连接逻辑。
- 不为本地终端显示该按钮。
- 不修改 SFTP 面板高度、拖拽比例或持久化设置。
- 不参与 Release 工作流，也不修改发布脚本。

## 验证

1. 已连接 SSH 且 SFTP 面板展开时，顶部不再出现命令按钮，状态栏在“传输记录”之前显示该按钮。
2. 折叠 SFTP 面板后，按钮仍可见并能打开或关闭终端底部命令输入。
3. SSH 已连接但 SFTP 尚未创建时，按钮仍可用。
4. 本地终端、文档标签和未连接 SSH 不显示该按钮。
5. 打开与关闭状态分别显示正确的中英文工具提示。
6. 窄窗口下路径或状态可以截断，命令、传输和展开/折叠按钮不重叠。
7. 运行 `cargo fmt --check`、相关测试、`cargo check --all-targets` 和严格 Clippy。

## 验收标准

- 命令输入切换入口只保留在 SFTP 状态栏中。
- 按钮顺序、显示条件和展开/折叠行为符合本设计。
- 命令输入框仍固定在终端底部，现有操作逻辑没有回归。
- 中英文界面不存在缺失翻译或误导性的固定“显示”提示。
