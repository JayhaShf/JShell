# Ashell 终端字体校准预览设计

## 目标

在修改正式终端的渲染参数前，先提供一个可交互的 HTML 预览，用于直接比较字体间距和宽高比例。Noto CJK 官方仓库没有发布 `NotoSansMonoCJKsc-Black.otf`，因此 Ashell 将按照约定，改为内置官方的 `NotoSansMonoCJKsc-Regular.otf`。

## 预览结构

预览页面是放在 `designs/` 目录下的独立本地 HTML 文件，使用当前 Ashell 的深色配色和紧凑 Windows 风格应用框架。页面同时提供三种查看方式，并使用完全相同的终端内容：

1. **三栏并排对比**：同时显示紧凑、均衡和宽松三种终端。
2. **单窗口切换**：通过分段控件在三套预设之间切换。
3. **完整校准视图**：显示一个完整尺寸的终端，并提供字号、单元格宽度、行高和网格显示控制。

所有视图与当前选中的预设保持同步。三套预设的“字号 / 单列宽度 / 行高”分别为：紧凑 `16px / 8px / 20px`，均衡 `17px / 9px / 23px`，宽松 `18px / 10px / 27px`。

## 渲染模型

页面通过 `@font-face` 加载 `../assets/fonts/NotoSansMonoCJKsc-Regular.otf`。终端示例使用明确的固定宽度单元格渲染，不依赖 CSS `letter-spacing` 模拟间距。ASCII 字符占一格，中日韩全角字符占两格，与正式终端的网格模型保持一致。可选的网格覆盖层只显示单元格边界，不改变布局。

示例输出覆盖英文字母、数字、标点、表格式内容、长路径、中文和 ANSI 风格颜色。三套预设的可见内容完全一致，确保对比时只有排版和信息密度发生变化。

## 正式字体调整

内置字体资源及 README 引用从 `NotoSansMonoCJKsc-Bold.otf` 改为官方 Regular OTF。配置中的字体族名称仍为 `Noto Sans Mono CJK SC`，现有用户配置可以继续使用。在用户选定预览方案前，不修改正式终端的字号、单元格宽度和行高。

## 交互与响应式布局

分段控件用于选择紧凑、均衡或宽松预设。滑块会立即更新完整校准终端，并显示精确的像素值。重置按钮将参数恢复为当前预设值。在窄屏视口下，三栏对比自动改为纵向排列，终端内容和控制项不得裁切或重叠。

## 验证

本地打开 HTML，并分别检查桌面和移动端视口。验证内容包括：内置字体正确加载、中文单元格宽度恰好是 ASCII 的两倍、三套预设具有清晰可见的差异、控制项能更新校准预览，以及界面文字没有重叠。字体换回 Regular 后，还需要执行 Rust 格式检查、完整测试和 release 构建。所有文件均不提交、不暂存。
