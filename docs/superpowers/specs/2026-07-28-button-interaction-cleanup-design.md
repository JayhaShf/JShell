# 按钮交互精简设计

## 目标

减少主工作区中重复的视觉元素和操作入口，同时完整保留 SSH 会话、会话文件夹、终端、文档编辑及 SFTP 工作流。所有保留下来的可见控件必须具备独立功能、能够打开菜单，或明确表示禁用及加载状态。

## 导航与布局

- 完整侧栏展开时不再渲染活动快捷栏，由侧栏独立承担左侧导航和性能监控功能。
- 侧栏折叠时显示一条宽度为 40 px 的窄栏，其中只保留“展开侧栏”按钮。
- 保留标题栏的会话选择器（`+`）、分屏按钮、终端搜索、设置按钮和 Windows 原生窗口控制按钮。
- 删除标题栏中使用放大镜图标、但实际打开会话选择器的重复按钮；会话入口统一使用 `+`。
- 删除侧栏中的设置按钮，因为标题栏和键盘操作始终可以打开设置。

## 行为修复

- 删除活动快捷栏中只有刷新界面、没有实际功能的监控按钮。
- 删除活动快捷栏内重复的会话选择、传输记录、新建 SSH 和设置入口。
- 已完成下载的“打开位置”操作改用跨平台 `open` 库，不再调用仅适用于 macOS 的 `open` 命令。
- 保留两组 `open-transfers` 和 `sftp-minimize-toggle` 标识；它们分别位于互斥的 SFTP 状态分支，运行时不会同时出现，不构成按钮冲突。
- 会话文件夹的展开/折叠、编辑、批量连接、复制/移动会话、克隆和删除功能保持不变。
- 传输任务的暂停、继续、取消和移除功能保持不变。

## 代码清理

- 删除当前没有被调用的旧版折叠侧栏渲染函数。
- 删除性能监控组件中永远无法执行的旧实现，并移除对应的警告抑制属性。
- 保留布局常量单元测试，并将折叠快捷栏宽度的预期值从 60 px 更新为 40 px。
- 为“打开已完成下载的位置”提取一个可测试的小型路径解析函数，使测试无需真正启动外部程序。

## 错误处理

- 操作系统无法打开下载位置时记录警告，软件界面保持可用。
- 这属于辅助操作，不额外增加错误弹窗。

## 验证方式

- 先运行新增的针对性测试，确认测试在实现修改前按预期失败。
- 运行 `cargo fmt --check` 和完整的 `cargo test`。
- 运行 `cargo build --release` 生成 Release 版本。
- 启动 Release 程序，检查侧栏展开/折叠、标题栏操作、SFTP 展开/收起、传输记录、设置、会话选择器、终端搜索和 Windows 窗口控制。
- 不创建提交，也不暂存文件。
