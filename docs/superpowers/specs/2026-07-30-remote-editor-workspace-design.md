## 目标

完善 JShell 的远程文件管理和编辑工作流：远程文件列表支持 Linux 权限展示和可靠删除，文件打开行为明确，编辑器支持全局自动换行、保存状态、混合分屏和独立窗口，SFTP 连接可以自动恢复，Windows 任务栏标题显示当前任务。

## 范围

本轮包含：

1. 当前 JShell 图标资源接入应用构建和运行时引用。
2. 远程 SFTP 文件权限展示、单击/双击行为和删除操作确认。
3. 全局自动换行偏好持久化。
4. 终端与远程文档共用的混合 Pane 树。
5. SFTP 稳定句柄、断线监视、退避重连和操作生命周期管理。
6. 编辑器保存状态、断线保护和独立编辑器窗口。
7. Windows 动态窗口标题和任务栏任务名。

现有 Tree-sitter 语法高亮继续使用；本轮不改为 Shiki。Shiki 评估结论保留在现有文档中。

## 用户交互

### 文件管理器

- 单击文件或文件夹行：只聚焦条目和更新预览，不勾选复选框，不打开文件，不进入目录。
- 双击文件行：在当前 SSH 工作区右侧打开内置编辑器。
- 双击文件夹行：进入该文件夹。
- 单击复选框：只切换批量选择状态。
- 右键菜单：保留下载、删除、内置打开、外部编辑等操作。
- 删除前显示确认；删除完成后刷新当前目录；正在删除的条目不可重复提交。

### 远程权限

SFTP 条目增加远程 Unix 类型和权限字段。文件列表展示符号权限和八进制权限，例如：

- 普通文件：`-rw-r--r-- 0644`
- 文件夹：`drwxr-xr-x 0755`
- 符号链接：`lrwxrwxrwx ...`

权限未知时显示 `--`，不得猜测。权限来源为 SFTP `FileAttributes.permissions`；保存文件时继续使用打开时的权限值，避免编辑器保存改变远程权限。

### 自动换行

自动换行是全局偏好，默认沿用当前关闭状态。切换后立即持久化，并应用到当前已打开文档、分页只读查看器和后续新文档。该偏好属于界面配置，不按单个文件保存。

### 混合工作区

当前 SSH 工作区默认使用左终端、右编辑器的混合布局。打开远程文件时：

- 创建一个远程文档模型，并在当前工作区 Pane 树右侧插入文档叶子。
- 文件仍保留为顶部文件标签，用于显示文件名、文件类型、脏状态和保存状态。
- 文件标签和文档 Pane 引用同一个文档模型，不创建两份文本或保存状态。
- 重复打开相同连接和路径时，只聚焦已有文档 Pane。
- 点击文件标签聚焦对应编辑器；点击 SSH 标签聚焦终端。
- `active_group` 始终表示当前 SSH 工作区，编辑器获得焦点时不能清空。
- `active_tab` 只表示当前终端；当前 Pane 类型和文档 ID从焦点路径派生。
- 关闭文档时移除文档叶子并压缩分割树，随后聚焦相邻终端或 Pane。
- 关闭最后一个终端但仍有文档时，将文档转为独立编辑器视图，保留文档和 SFTP 句柄，不静默丢弃内容。

## 混合 Pane 架构

将现有仅支持终端字符串叶子的 `PaneLayout` 改为类型安全的混合叶子：

- `Terminal(String)`：本地、SSH、串口终端。
- `Document(String)`：远程文档 ID。
- `Empty`：替代空字符串哨兵，避免把空终端 ID或空文档 ID误认为有效内容。

布局仍保留现有横向/纵向分割和比例调整。增加按类型遍历的辅助方法：终端 ID、文档 ID、全部叶子、指定内容路径和当前焦点内容。

终端相关逻辑只能读取终端叶子：终端状态聚合、系统监视、终端搜索、终端关闭、终端复制和终端滚动不得把文档 ID当作终端 ID。文档相关逻辑负责文档关闭、保存、焦点和脏状态。

`TabGroup` 保存混合布局和当前焦点路径。切换工作区时同时恢复布局和焦点，避免每次切换都回到第一个终端。

## SFTP 连接监视

每个 SSH 工作区拥有一个稳定的 `SftpHandle`。句柄背后的 supervisor 管理可替换的内部连接，文档后端不随着断线重连而重新绑定。

### 连接状态

连接状态至少包含：连接中、已连接、正在重连、离线、已关闭。每次成功连接分配递增代次。事件携带工作区 ID和连接代次，应用层丢弃旧代次的迟到事件。SFTP 不复用终端 `Closed` 事件。

### 重连策略

断线后按 `1、2、4、8、16、30` 秒退避，之后保持 30 秒重试；成功后退避重置。关闭 SSH 工作区或最后一个 SFTP 句柄释放时取消监视任务。

SFTP 面板显示当前状态、最近错误和立即重连按钮。重连成功后刷新当前目录，并让后续文档读写继续使用同一个稳定句柄。

### 命令生命周期

自动重试只适用于无副作用读取：目录刷新、预览、文件读取和文件状态查询。每个请求有唯一 ID和唯一完成路径，连接切换、取消和关闭时都必须让等待方得到明确结果。

保存、删除、创建目录、上传和下载一旦进入执行阶段，断线后标记为失败或结果未知，不自动重新排队。这样可避免远程操作已经成功但响应丢失后再次执行。

传输任务必须在连接建立失败、传输中断和取消时进入终态，不能永久停留在运行中。自动外部编辑上传继续使用单飞约束，旧上传完成后不得覆盖更新的内容。

### 文档断线行为

断线不会调用保存函数。编辑内容只保留在当前编辑器内存中，远程文件保持原内容。重连成功后由用户明确点击保存；保存前继续执行远程状态检查和冲突检测。

如果保存已经开始后连接断开，结果可能未知。文档保持脏状态，显示结果未知或失败，不自动重试，避免盲目覆盖远程文件。

## 编辑器窗口与状态

独立编辑器窗口引用主应用中的同一文档模型、输入状态、SFTP 后端和保存状态，不复制文本。分屏编辑器通过窗口操作移出到独立窗口，关闭窗口后重新放回原工作区；原工作区已关闭时保留为独立文档视图。

独立窗口有独立的关闭保护：无未保存内容时直接关闭，有未保存内容时复用现有保存确认流程。编辑器工具栏和底部状态栏统一显示加载中、已保存、未保存、保存中、冲突、失败、离线和结果未知。

## Windows 标题

标题由当前工作区状态统一同步：

- 默认：`JShell`
- 混合工作区：只显示当前聚焦文件名，例如 `JShell - nginx.conf`。
- 混合工作区有多个文件时，显示当前聚焦文件名。
- 独立编辑器窗口：`JShell - 文件名`。
- 没有文件时，终端显示会话名或本地终端名。
- 未保存文件名后增加 `*`。

标题不包含密码、完整敏感路径或配置内容。SSH 终端动态标题变化和编辑器保存状态变化都通过统一同步函数更新窗口标题，避免每次渲染重复写入系统标题。

## 错误处理

- 旧连接事件、旧文档异步事件和旧请求结果不得覆盖当前状态。
- SFTP 连接错误统一映射为可识别的连接关闭错误，权限错误、文件不存在和协议错误保持原始语义。
- 文档加载、分页读取和保存继续用 operation ID拒绝过期结果。
- 删除、保存和传输失败必须在状态栏显示原因，并保持可重试入口。
- 关闭窗口、关闭工作区和句柄释放时取消后台任务并结束所有等待请求。

- 退避序列、成功重置和关闭取消。

- 最后一个终端关闭时文档转为独立视图且内容不丢失。
